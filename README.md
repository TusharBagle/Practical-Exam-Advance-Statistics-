## 🚀 About The Project

**Mathematics & Advanced Statistics** is a comprehensive Python-based practical project developed to explore the mathematical and statistical concepts that form the foundation of modern Data Science.

This project combines theoretical understanding with practical implementation using Python, statistical libraries, mathematical formulas, data analysis techniques, and graphical visualizations.

Using a real-world-style **Loan Applications Dataset**, the project demonstrates how statistical methods can transform raw financial data into meaningful insights and support data-driven decision-making.

Rather than simply calculating statistical values, the objective is to understand the mathematics behind each technique, implement it programmatically, visualize its behaviour, and interpret the results.

## 🎯 Project Objectives

- Understand the mathematical foundations of advanced statistics.
- Apply descriptive and inferential statistical techniques.
- Explore probability theory and random variables.
- Analyze distributions and identify patterns in financial data.
- Measure skewness, kurtosis, variance, and standard deviation.
- Understand relationships between variables.
- Apply statistical transformations and normality tests.
- Develop mathematical thinking through Python programming.
- Interpret statistical results for practical decision-making.

## 📈 Dataset Overview

The project uses `loan_applications.csv`, a dataset representing loan application information.

Key variables include:

| Feature | Description |
|---|---|
| Credit_Score | Creditworthiness indicator of a customer |
| Loan_Amount | Amount of loan requested or associated with a customer |
| Income | Customer's income |
| Default_Status | Indicates whether a customer has defaulted |

The dataset provides an opportunity to apply statistical methods to financial data and understand customer behaviour through mathematical analysis.

## 📊 Data Visualization

Visualizations are an essential part of this project because they make statistical patterns easier to understand and interpret.

The project includes graphical analysis such as:

- Histograms for understanding data distributions.
- Skewness analysis for measuring distribution asymmetry.
- Kurtosis analysis for examining distribution tails.
- Q-Q plots for assessing normality.
- Statistical charts for exploring financial variables.

All generated visualizations are organized inside the `Images/` directory.

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

**Step 1: Clone the repository**

```bash
git clone https://github.com/TusharBagle/Practical-Exam-Advance-Statistics-.git
```

**Step 2: Navigate to the project directory**

```bash
cd Practical-Exam-Advance-Statistics-
```

**Step 3: Install the required libraries**

```bash
pip install numpy pandas matplotlib seaborn scipy jupyter
```

**Step 4: Launch Jupyter Notebook**

```bash
jupyter notebook
```

**Step 5: Open the practical notebook**

Open `Practical Exam.ipynb` and execute the cells sequentially.
